# DSA Journey

My learning log for Data Structures and Algorithms, primarily using C++. The goal is to understand patterns and trade-offs, not simply collect solved problems.

## Suggested learning order

- [ ] Complexity basics: time and space, Big O
- [ ] Arrays and strings
- [ ] Searching and sorting
- [ ] Hashing and frequency counting
- [ ] Two pointers and sliding window
- [ ] Recursion and backtracking
- [ ] Linked lists
- [ ] Stacks and queues
- [ ] Trees and binary search trees
- [ ] Heaps and priority queues
- [ ] Graphs
- [ ] Greedy algorithms
- [ ] Dynamic programming

## Repository structure

- `arrays/` — array patterns and exercises
- `strings/` — string problems
- `searching-sorting/` — common algorithms
- `recursion/` — recursive thinking and backtracking
- `problem-log.md` — record of attempted problems
- `problem-template.md` — reusable write-up format

## How to record a solution

For each problem, note the idea in your own words, correctness reasoning, complexity, edge cases, and what you learned. If you needed a hint or looked at a solution, record that honestly and revisit the problem later.
